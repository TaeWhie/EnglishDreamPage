영어드림 수강 규정

수강생분들의 편리한 예약 관리와 효과적인 학습 유지를 돕기 위하여
체계적이고 정밀하게 조율된 수강 관련 정책을 안내합니다.

수강 안내 및 규정

학습 시작 전에 수업 연기, 보강, 중지 등의 수강 규정을 꼭 확인해 주시기 바랍니다.

수업 연기

수강권 당 가능한 횟수 내에서 일반 연기 또는 당일 연기 가능
일반연기/보강연기 신청 후 취소 불가
자유예약은 일반 연기 및 보강 연기 불가

<수업별 연기 가능 횟수>

  • 주2회 수업 : 총 1회 연기 가능
  • 주3회 수업 : 총 2회 연기 가능
  • 주5회 수업 : 총 3회 연기 가능

일반 연기 & 보강 연기 (당일)

일반 연기

  • 등록된 수강의 마지막 수강 일자가 다음 수강 일자로 미루어 지는 것 (하루 전, 자정까지 신청 가능)
  • 40분 수업의 경우 각각의 수강권에서 연기 신청해야 함.
  • 수강 하루 전일, 자정 전까지 사이트에서 연기 신청해야 함.

ex) 12회 수강 기준 등록된 마지막 수업이 8월 28일인 경우, 1회 수업 연기 시 30일 종료 일자로 연기

보강 연기 (당일 연기)

  • 등록된 수강 시간/요일에 관계없이 변경하여 수강하는 것.
  • 수강 당일에만 신청 가능하며, 수강 1시간 전까지 사이트에서 연기 신청해야 함.
  • 토요 집중 수업은 보강 연기 불가

ex) 월요일 15:00 수강 -> 월 06:00 ~ 화 23:30 중 선택 가능

자유 예약

  • 사용 기간은 자유예약 수강 등록일부터 공휴일 포함 30일이며, 미 소진 시 잔여 횟수는 자동 소멸 됨.
  • 자유 예약은 수강 연기, 보강 연기(당일 연기), 수강 시간 변경, 수강 중지, 수강 취소 불가
  • 1일 횟수 제한 없이 가능한 잔여 횟수 내에서 수강 신청 가능
  • 수강 신청은 수강 시작 1시간 전까지 신청 가능하며, 신청일로부터 2일 이내로 예약 가능 (예시 : 8월 3일 수강 신청 시 8월 4일 수강까지 예약 가능)
  • 자유예약 수강은 과정 변경만 가능 (담당 플래너를 통해서 수강 6시간 전까지)

수업 중지

2주 이상 수강 진행 불가 시 수강 중지 가능

<수업별 중지 가능 횟수>

  • 주2회, 주3회, 주5회 : 1개월 수강권 당 1회 중지 가능. (1개월 수강권 기준 : 주2회 - 8회 / 주3회 - 12회 / 주5회 - 20회)
  • 수강시간 2시간 전까지 홈페이지에서 중지 가능.
  • 중지 후 2주 이내 재등록 불가 / 중지 후 6개월 이내 재등록해야 함.
  • 기간 내 미등록 시 등록된 전체 수강권 및 잔여 횟수 소멸되어 사용 불가.
  • 재등록 시 담당 강사님 변경될 수 있음.

수업 휴강일 & 녹화 영상

수업 휴강일

  • 한국 공휴일 : 휴강
  • 대체 공휴일의 경우 당사 사정에 따라 휴강 여부 사전 공지

녹화 영상

  • 수업 영상은 자동 녹화 되며, 3주간 제공 됨.
